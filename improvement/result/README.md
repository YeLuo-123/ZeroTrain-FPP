# Improvement 实验结果

本目录仅保存基于老师 U-Net 改写的多任务分界线网络实验产物。

## 当前结果

- `boundary_multitask_smoke/`：5张训练样本、1张验证样本、1 epoch、base=8 的 CUDA 链路测试，包含 `best.pth`、`latest.pth`、训练历史和运行清单。
- `boundary_multitask_inference_smoke/`：加载 smoke 权重后的推理及 K2→K64→Phi64 物理展开结果。
- `phase_boundary_dataset_v2/`：f=2/f=64、240×320、带噪声的120个V2场景。
- `boundary_multitask_run_120/`：102个训练场景、18个验证场景、20 epochs、base=16 的正式运行结果。
- `comparison_f2_f64/`：在固定18场景验证集上与传统检测、PCHIP和Oracle进行的同协议对比。

前两个 smoke 目录只证明代码链路可以运行。`boundary_multitask_run_120` 是本轮小规模实验，适合用于方案筛选；由于比较使用训练期间的验证集而非独立测试集，仍不能作为最终论文结果。

## 本轮同协议结果

| 方法 | K2准确率 | K64准确率 | Phi64 MAE/rad | 灾难性错误率 |
|---|---:|---:|---:|---:|
| 传统检测（缺失行不补全） | 81.77% | 80.39% | 37.0165 | 18.47% |
| PCHIP补线 | 94.73% | 93.06% | 11.0445 | 5.56% |
| 改进网络K2 + 观测相位 | **99.21%** | **97.28%** | **2.2254** | **1.18%** |
| 改进网络K2 + 网络修复相位 | 99.21% | 60.60% | 5.9946 | 6.00% |
| Oracle K2 | 100.00% | 97.98% | 0.7938 | 0.46% |

结论：当前网络的 K2/边界学习有效，但相位头精度尚不足以经受32倍频率放大。现阶段推荐使用“网络预测K2 + 三步观测相位 + 物理展开”。
