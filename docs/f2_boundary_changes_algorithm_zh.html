1. 源代码原本解决什么问题

Exp3_Simulation.m 前半部分研究的是：通过一次相机曝光内叠加 多种内部相移图案，抑制三步相移中的五次谐波误差。

原始条纹模型为：

I=A+BcosΦ +B5cos(5Φ)

原代码使用 f=3、3个外部相移步和12个内部相移状态。内部相移量为：

δm= 2πm12 ,m=0,…,11

每个内部状态的理想投影次数为：

Smideal =c(1+cosδm)

取整后得到：

S = [20, 19, 15, 10, 5, 1, 0, 1, 5, 10, 15, 19]
总投影次数 = 120 次 / 相机曝光

一次外部相移曝光记录为：

Jk= ∑m=011 Sm [A+Bcos(Φ+αk+δm) +B5cos(5(Φ+αk+δm))]

权重 1 + cos δm 只包含直流和一阶频率成分， 五次谐波与该权重正交，因此理想情况下五次谐波可以在积分中抵消。 整数取整后仍有少量残差。本次数值复现得到 c2=61.1769、 c3≈0，五次谐波剩余谱幅值为1.1769。

3. 从单频仿真改为双频二维结构光仿真

当前方案首先生成二维归一化投影仪坐标：

up(x,y)∈[0,1)

坐标场包含横向线性分量、随 y 变化的正弦表面、局部凸起/凹陷和小幅二维波纹。 低频和高频绝对相位由同一投影坐标生成：

Φ2=2π·2up=4πup Φh=2πfhup

当 fh=48 时：

Φh=482Φ2=24Φ2

4. 基频2为什么会产生分界线

基频2的真实相位范围是 [0,4π)，而三步相移只能得到 [0,2π) 的包裹相位：

φ2=mod(Φ2,2π)

因此需要二值条纹级：

K2= ⌊Φ22π⌋ ∈{0,1}

基频绝对相位为：

Φ2=φ2+2πK2

K2=0 和 K2=1 两个区域的交界为：

Γ={(x,y)|Φ2(x,y)=2π}

几何上，该边界对应物体表面与投影仪某个等相位平面的交线。当前仿真假设 每一图像行最多有一个边界位置，可写为 xΓ(y)。

5. 三步相移解相及相位约定的修改

普通三步观测的正余弦累加量为：

C=∑k=02Ikcos2πk3 S=∑k=02Iksin2πk3

当前采用：

φ=mod[−atan2(S,C),2π]
源代码中的 -atan2(...)+pi 对其前半部分明确使用的 I=A+BcosΦ 模型会引入约 π 的相位偏移。因此当前对比保留源代码的内部叠加 算法意图，但使用与仿真模型一致的 mod(-atan2,2π) 相位约定。

6. 源代码内部叠加的解调补偿

整数投影次数使叠加后的基波变成 c2cosΦ+c3sinΦ。设三幅叠加图像的普通累加量为 C、S，则当前按照源代码构造：

D=c2C+c3S N=−c3C+c2S

再计算：

φ=mod[−atan2(N,D),2π]

原MATLAB前半部分只在 f=3 上展示内部叠加。目前将相同权重和解调公式分别 用于 f=2 和 f=48，以便所有方法在同一双频协议下公平比较。

7. 新增物理质量图

源代码没有显式计算相位质量。目前根据三幅图计算均值、调制度和相对质量：

A=I0+I1+I23 B=23C2+S2 Q=B|A|+ε

Q 用于排除低调制度区域、抑制阴影中的随机跳变，并作为后续置信度的物理依据。

8. 传统分界线检测

对相邻像素定义相位差：

d(x,y)=φ2(x+1,y)−φ2(x,y)

候选分界点需满足：

d(x,y)<−π 且 min(Qx,Qx+1)>TQ

候选得分为：

s(x,y)=−d(x,y)min(Qx,Qx+1)

每行选择得分最高的位置作为 xobs(y)；没有可靠候选的行记为缺失。

9. 新增全局与局部伪边界剔除

9.1 全局位置筛选

对所有已检测位置计算中位数和中位绝对偏差：

m=median(xobs) MAD=median(|xobs−m|)

距离主边界位置过远的连续伪跳变会被删除。

9.2 局部连续性筛选

对边界轨迹进行局部中值估计。若某一点偏离相邻行的中心位置过大， 则将其视为孤立伪边界。其物理依据是：连续表面上的等相位边界不应在相邻行间 无原因跳跃几十个像素。

10. 分界线补全算法

当前验证阶段采用确定性的PCHIP保形三次插值：

x^Γ(y)=PCHIP{(yi,xi)}

补全过程遵循以下原则：

  • 传统算法已经检测到的可靠物理种子保持不变；
  • 只补充缺少可靠检测的图像行；
  • 使用保形插值避免普通高阶样条在长缺口处严重过冲；
  • 输出限制在图像有效范围内；
  • 将边界覆盖率提升到100%。

11. 从完整边界恢复二值级次

当前仿真假设投影相位沿 x 方向增加，因此：

K^2(x,y)= 0x<x^Γ(y) 1x≥x^Γ(y)

基频绝对相位随之恢复：

Φ^2=φ2+2πK^2

这一步是当前方案与源代码最根本的区别：源代码主要修正连续相位误差， 当前方案显式恢复离散级次区域及其拓扑边界。

12. 高频相位展开及错误放大

高频条纹级为：

K^h= round[ fh2Φ^2−φh 2π ]

高频绝对相位为：

Φ^h=φh+2πK^h
当 fh=48 时，若基频级次错1级，则基频绝对相位错2π， 对应高频条纹级理论上可能一次错 48/2=24 级。因此边界错误不是普通的小相位误差， 而是可能造成大片高频相位跳变的灾难性拓扑错误。

13. 当前实验增加的五个对照组

  1. Traditional 3-step：普通三步，不使用内部叠加，也不补边界。
  2. Source IPS：复现12步内部叠加及 c2/c3 解调，但不补边界。
  3. F2 boundary completion：普通三步观测，只执行分界线检测、伪边界剔除与补全。
  4. IPS + boundary completion：先抑制谐波，再补全基频2分界线。
  5. Oracle boundary：普通三步直接使用真实边界，表示普通三步观测下边界完全正确时的上限。

14. 为什么两种方法具有互补性

总误差可以粗略分为：

E=Econtinuous+Etopology
  • 连续误差：噪声、谐波、Gamma和非正弦引起的周期内相位误差；
  • 拓扑误差：分界线断裂造成的离散条纹级区域错误。

源代码内部叠加主要降低连续误差；分界线补全主要降低拓扑误差。因此组合方案优于任一单独方案。

15. 当前方案与最终神经网络方案的关系

当前PCHIP补全器用于验证研究假设，还不是最终创新网络。它已经验证： 分界线缺失是重要误差源；正确恢复边界能改善K2；K2改善能够传递到高频相位； 内部叠加与边界补全具有互补性。

下一步应将确定性插值替换为边界—级次多任务网络：

{PΓ,P(K2=0), P(K2=1),C} =Fθ(I2,0:2,φ2,Q,Mseed)

网络应联合输出分界线概率、二值级次区域、相位修复结果和像素置信度，再继续使用现有物理公式展开高频相位。

16. 当前算法的适用条件与限制

目前得到验证的条件：

  • 每行只有一条可表示为 xΓ(y) 的平滑基频2边界；
  • 缺失区域两端存在可靠物理种子；
  • 低频边界缺口处，高频仍保留部分调制度；
  • 物体静止，相机积分和内部微投影近似线性；
  • 当前评价为相位误差，不是经标定后的毫米深度误差。

尚未解决的情况：

  • 多个不连通物体、一行多个边界或边界分叉；
  • 完全无观测的大面积遮挡；
  • 三步图像之间的物体运动；
  • 真实相机饱和和投影仪非线性；
  • 相机—投影仪联合标定误差及真实毫米级三维重建。
最终判断：目前方案是在源代码“连续相位谐波抑制”的基础上， 增加“基频2离散级次拓扑恢复”。两部分分别处理不同类型的错误，组合后明显优于 单独使用源代码方案或单独补全分界线，但真实系统结论仍需通过双频三步采集验证。
